# 🎮 Pong Game

Класична гра Pong, розроблена на ванільному JavaScript з використанням Canvas
API. Це двоґравцева гра з сучасним ретро-дизайном.

## 📋 Опис проекту

Це реалізація популярної гри Pong — однієї з перших комп'ютерних ігор. Гравець
керує ракеткою, щоб відбивати м'яч і набирати очки проти комп'ютерного суперника
з інтелектуальним AI.

## 🎯 Можливості

- ✅ Гра проти AI (комп'ютера)
- ✅ Інтелектуальний суперник з адаптивним поведінням
- ✅ Реалістична фізика м'яча з прискоренням
- ✅ Система набору очок
- ✅ Прискорення м'яча кожні 10 секунд гри
- ✅ Ретро-дизайн з використанням шрифту "Press Start 2P"
- ✅ Управління стрілками клавіатури

## 🕹️ Як грати

1. Відкрийте файл `index.html` у веб-браузері
2. Натисніть **пробіл** щоб запустити м'яч
3. **Ваша ракетка** (ліва): керуйте з допомогою клавіш **↑** (вгору) та **↓**
   (донизу)
4. **Комп'ютер** (права ракетка): грає автоматично з AI
5. Відбивайте м'яч і набирайте очки
6. Перший, хто набере **10 очок**, перемагає!

## 🛠️ Технології

- **HTML5** — структура сторінки
- **CSS3** — стилізація з ретро-дизайном
- **JavaScript (ES6+)** — логіка гри та фізика
- **Canvas API** — рендеринг графіки

## 🔧 Встановлення

Для запуску гри не потрібна додаткова інсталяція:

1. Клонуйте репозиторій або завантажте файли
2. Відкрийте `index.html` у вашому браузері
3. Починайте грати!
